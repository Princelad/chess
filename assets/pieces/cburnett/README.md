# cburnett (bundled piece set)

Classic staunton-style SVG chess pieces by **Colin M.L. Burnett**.

- Source: `lichess-org/lila`, `public/piece/cburnett/`
  (<https://github.com/lichess-org/lila>); locally rasterized to
  160×160 RGBA PNGs.
- The same artwork is hosted on Wikimedia Commons
  ("Cburnett chess pieces") by the author under
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/);
  lila's COPYING.md additionally lists the set as GPLv2+.
